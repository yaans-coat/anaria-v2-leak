# anaria!
a sick web proxy

[![join the discord!](https://invidget.switchblade.xyz/VPq3CD6d7B)](https://discord.gg/VPq3CD6d7B)

## why should i use it?
- slick ui
- games and webgl emulated content from different sources
- built in movies, music and anime
- cloud sync for syncing browsing data and etc.
- proxied search with your favouraite browsers
- very cool...

## live instance

[anaria!](https://anaria.fun)

## self-hosting

```bash
#cloning
git clone https://github.com/yaans-coat/anaria

#setup
cd anaria
npm install
node server.js
```
